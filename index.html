Which chart should I use?

Start with one question: how many parts can you sensibly measure together at each check?

ChartUse when
I-MR
n = 1		Only one reading makes sense per check: one value per batch or heat (bath pH, furnace temperature, hardness per heat-treat load), destructive or expensive tests (pull force, burst test), slow processes (a few parts per shift).
X̄–R
n = 2 to 9		Parts are quick and cheap to measure and come off the machine one after another: machining, moulding, stamping, crimping. The shop-floor standard; usually n = 3 to 5 consecutive parts.
X̄–S
n ≥ 10		Large subgroups, or the calculation is done by software or an automatic gauge. S uses every reading; R only uses the largest and smallest, so it loses information as n grows.

Rule for any subgroup: the parts in one check must be made under the same conditions (same machine, cavity or spindle, consecutive parts). Mixing cavities, spindles or batches in one subgroup hides real problems.

Continuous processes (steel, aluminium, chemicals, paper): most data is one value per heat, cast, coil or pot, so I-MR is the everyday chart. Two traps: readings taken seconds apart from an online gauge are related to each other, which makes limits too tight; and if you subgroup readings within a coil, the X̄ chart will flag every coil-to-coil difference. Chart one value per coil (I-MR), or use an I-MR-R chart.

Counting instead of measuring? (good/bad, number of defects) Use attribute charts: p or np for defectives, c or u for defects. They are not covered in this simulator.

Cm, Cp or Pp: which data, which formula?
IndexDataσ used
Cm / CmkAbout 50 consecutive parts: one machine, one setup, one operator, one lot. Used for machine acceptance.Std dev of all readings
Cp / CpkSubgroups collected over time (e.g. 25 × 5). Cpk is only valid when the control chart is stable. Used for ongoing production.σ within: R̄/d2, s̄/c4 or MR̄/1.128
Pp / PpkThe same subgroups as Cp/Cpk. Used for PPAP / initial studies, and whenever the process is not stable.σ overall: std dev of all readings

Cp vs Pp: same data, different calculation. Cm vs Pp: same calculation, different data. Cm is high because its data is "clean", not because the formula is special.

Cm is not defined in the AIAG SPC manual; it comes from customer and OEM procedures, and details vary. Typical: Cm ≥ 2.0, Cmk ≥ 1.67. Some customers divide by 8s instead of 6s. Always check the customer's requirement.

Why can I set the "true" process here?
On a real shop floor nobody knows the true average or spread; you only see measured parts. These settings are the simulator's "behind the scenes" knobs. Every number in the results panel is estimated from the measured parts only, exactly as you would do it on the floor.

What do the rules look for?
PatternUsually means
Point beyond a limitA sudden change: offset, tool, lot, operator.
7 in a row on one sideThe average has shifted.
7 in a row up or downA drift: tool wear, warm-up.
Extra patterns ("All 8")
2 of 3 beyond 2σEarly warning of a shift (outer third of the chart).
4 of 5 beyond 1σEarly warning of a smaller shift.
15 in a row within 1σPoints hug the centre: mixed streams in a subgroup, or out-of-date limits.
8 in a row outside 1σPoints avoid the centre: two sources mixed (machines, cavities, operators).
14 alternating up/downSaw-tooth: over-adjustment, or two alternating sources.

More rules catch problems earlier but also raise more false alarms. Many plants use the basic three plus one or two extras. A single pattern signal on a long run can be chance; a point beyond a limit rarely is.

What the chart is saying

Control chart constants and capability guidance follow the AIAG SPC reference manual. Basic rules: a point beyond a control limit; 7 points in a row on one side of the centre line; 7 points in a row going steadily up or down.
